# 混合参会 — 音频与检点策略

## 会场模型

| 参会方式 | 到场确认 | 音频 |
|----------|----------|------|
| **线下** | 主持 TTS 逐一点名 + 现场单麦 ASR 答到 | 会议室操作员链接推流至 `/ws/audio` |
| **线上** | 个人入会链接 `/join/{meetingId}?token=…` 打开即 `POST /check-in` | **禁止推流**（JWT `can_push_audio=false`） |

## 配置

- `meeting.host.roll-call.online-inventory-seconds`：线上盘点窗口（默认 60 秒），结束后进入线下点名。

## API

- `GET /api/v1/meetings/{id}/participant-links` — 列出参会人及个人 `joinUrl`（仅 `attendance_mode=ONLINE`）
- `POST /api/v1/meetings/{id}/check-in` — 线上到场（Bearer 个人入会 JWT）

## 数据

`int_meeting_participant` 字段：`attendance_mode`、`checked_in_at`、`check_in_source`。

创建会议时在 `participants[].attendanceMode` 指定 `OFFLINE` / `ONLINE`；未指定默认为 `OFFLINE`。
