3.2 已识别的改进项（非阻塞）
以下为代码审查过程中发现的优化建议，按优先级分类：

🟡 中优先级建议
异常处理统一化：建议添加 @RestControllerAdvice 全局异常处理器，统一 4xx/5xx 状态码
前端 XSS 防护：管理后台部分 JS（push-bot.js、weekly-jobs.js）存在直接 innerHTML 操作，建议统一使用 textContent 或转义函数
JWT 传递方式：URL 查询参数传递 token 存在日志泄露风险，建议优先使用 Authorization Header
Internal Controller 认证：InternalMeetingController 等内部端点建议添加 X-Internal-Token 校验
FeishuWebhookController 体积：850+ 行单文件可考虑按职责拆分
🟢 低优先级建议
硬编码 fallback 用户 ID 建议添加过期清理机制
内嵌在 VoiceprintRegisterController 中的 HTML/CSS/JS 建议抽离为静态模板
ui-kit 部分组件从外部 CDN 动态导入，建议评估自托管可能性
