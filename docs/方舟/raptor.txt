## 三、仍存在的代码级问题（源码确认）

### 🔴 CRITICAL 级别（必须上线前修复）

#### NEW-CRIT-01：InternalMeetingController 完全无鉴权
- **文件**：`meeting-server/src/main/java/com/smartmeeting/api/controller/InternalMeetingController.java`
- **路径**：`/api/v1/internal/meetings`
- **问题**：该控制器位于 internal 路径下，但与其他 4 个 internal 控制器不同，**未注入 InternalApiAuth，未调用 requireToken()**
- **暴露端点**：
  - `PUT /{meetingId}` → 更新会议全部字段
  - `PATCH /{meetingId}/schedule` → 会议改期
  - `POST /{meetingId}/participants` → 任意添加参会人
  - `PUT /{meetingId}/participants/{participantId}` → 任意修改参会人
  - `DELETE /{meetingId}/participants/{participantId}` → 任意删除参会人
- **影响**：任何能访问 8765 端口者可篡改任意会议数据

#### NEW-CRIT-02：RecordingController 无鉴权即可生成高权限 JWT
- **文件**：`meeting-server/src/main/java/com/smartmeeting/api/controller/RecordingController.java`
- **问题**：两个 GET 端点无任何鉴权，仅凭 meetingId 即可生成 JWT：
  - `GET /{id}/recording-url` → 生成录音操作员 JWT（可开始/停止/暂停录音）
  - `GET /{id}/host-url` → 生成主持人 JWT（可全程控制会议：推进议程、点名、结束会议）
- **影响**：知道 meetingId（UUID 可枚举或从飞书卡片链接获取）即可获得会议主持人权限，并持久化 token 到数据库

#### HIGH-09：Scheduled Push 表缺失于运行时 schema.sql
- **文件**：`meeting-server/src/main/resources/schema.sql` vs `sql/schema-final-ddl.sql`
- **问题**：6 张推送相关表（int_scheduled_push_task 等）仅存在于 sql/ 目录下的 DDL 文件中，不在 Spring Boot 自动初始化的 schema.sql 中
- **影响**：docker-compose 新环境启动后推送管理功能直接报表不存在错误

#### HIGH-13：OutboxPoller 无并发防护
- **文件**：OutboxPoller 轮询逻辑
- **问题**：使用普通 SELECT 无 FOR UPDATE SKIP LOCKED，无 claimed_by 字段
- **影响**：多实例部署会导致事件重复投递

## 七、问题优先级与修复建议

### 🔴 P0 - 上线前必须修复（4 项）

1. **InternalMeetingController 添加鉴权**：注入 InternalApiAuth，在每个方法开头调用 `requireToken(request)` 校验 X-Internal-Token（参照其他 internal 控制器）
2. **RecordingController 添加鉴权**：`/recording-url` 和 `/host-url` 需要求 host operator JWT 或 internal token，不能匿名生成高权限 token
3. **补全 schema.sql**：将 sql/schema-final-ddl.sql 中的 6 张推送表 DDL 合并到 meeting-server/src/main/resources/schema.sql
4. **OutboxPoller 加行锁**：使用 `SELECT ... FOR UPDATE SKIP LOCKED`（MySQL 8 支持）或添加 claimed_by/claimed_at 字段

### 🟠 P1 - 近期修复（6 项）

5. 评估 8765 端口暴露面，必要时 MeetingController 添加鉴权或反代层保护
6. 清理 application-dev.yml 中的生产密钥，改用占位符
7. AdminSessionStore 迁移 Redis 或添加 @Scheduled 定期过期清理
8. XfyunRealtimeSessionPool 添加 @PreDestroy disconnectAll()
9. 核心 @ConfigurationProperties 添加 @Validated 校验
10. 删除 ADMIN_TOKEN 默认弱口令 dev-admin-token

### 🟡 P2 - 后续迭代

11. meeting-admin-server 补充 Controller/Service 层测试
12. 添加 meeting-server Controller 层鉴权集成测试（Spring MockMvc）
