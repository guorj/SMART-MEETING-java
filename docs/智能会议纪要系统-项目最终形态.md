# 智能会议系统 —— 项目最终形态

> 一句话定义：一个以飞书为入口、AI 主持人为中枢的「零操作」会议闭环系统——人只需要到场、发言、决策，从会议发起到待办落地，全链路无人值守。
> 编制日期：2026-05-14

---

## 一、用户视角：一场会议的完整体验

### 会前 24 小时——你什么都不用做

系统检测到「每周一 9:30 综合管理会」的周期（周五17：00）到了，自动执行：

1. 按 5 号预设模板创建会议，本次会议事项清单从上周待办 + 群内新议题 + 用户自行添加（如有）自动聚合。
2. 飞书群弹出一张卡片：「📋 综合管理会 · 周一 9:30」，列出议程、会议事项、参会人、上次待办完成率。
3. 每位参会人收到「参加 / 请假」按钮——24h 内不操作默认参加。
4. 参会人张三点「请假」→ 系统判断非关键决策人(无相关议题涉及) → 记录，不阻断流程,参会人李四点「请假」→ 系统判断为关键决策人（组织者、主导者、有相关议题涉及） → 推送消息给会议组织人，确认会议是否延期
5. 确认率达标 → 系统调飞书日历 API 创建日程 + 预约 3 楼会议室 A + 把上次纪要链接附进邀约。
6. 飞书日程推到所有人日历上

### 会前 10 分钟——你只需要点一下

7. 飞书群弹出「会前盘点卡片」：谁已签到、谁声纹就绪、谁上次待办延期。点「签到」+ 点「进入会议」。

### 会中 60 分钟——你只需要发言和决策

8. 9:30 到了，AI 主持人自动开场——音箱里传出声音：「会议开始，今天议程分为 5 项，预计 60 分钟。」
9. 大屏/浏览器上，虚拟主持人播报。
- 以下内容按不同会议适配
10. AI 主持人报上次待办：「上次会议 5 项待办，3 项已完成，1 项进行中——张三的 Q2 前端重构，请说明延期原因。」张三开口解释
11. AI 主持人切换到议题一：「现在进入议题一：Q2 经营数据回顾，预计 15 分钟。」
12. 你发言。你旁边的人发言。屏幕上实时显示转写文字，每句话都启用了声纹分离——「speaker01 (09:35)：Q2 收入同比增长 12%……」「speaker02 (09:36)：Q3 计划.....」
13. 14:29，AI 主持人提醒：「议题一还剩 1 分钟」，不加时则无需操作
14. 14:30，AI 主持人：「议题一时间到。」自动切到「下一议题」。
15. 理想状态全程无需干预

### 会后 5 分钟——你什么都不用做

16. 发起人点「结束会议」→ AI 主持人：「会议结束，纪要生成中，感谢各位。」
17. 系统自动：离线校正 → 声纹识别补全 → LLM 生成结构化纪要 → 创建飞书文档 → 写入。
18. 飞书群弹出：「✅ 纪要已生成」，含文档链接。
19. 系统自动：从纪要提取待办 → 匹配责任人 → 创建飞书任务 → 飞书群弹出：「📌 待办 3 项，已同步责任人」。
20. 张三飞书收到任务：「完成 Q2 前端重构方案，截止 5 月 20 日」。

### 会后两周——你什么都不用做，但待办不会消失

21. 每日飞书提醒张三，「⏰ 待办「Q2 前端重构方案」还剩X日；
5 月 19 日 18:00，张三飞书弹出：「⏰ 待办「Q2 前端重构方案」还剩 24 小时」。
点「标记完成」或「申请延期」。
22. 5 月 20 日过了截止 → 系统自动标 DELAYED → 张三上级收到：「⚠️ 张三的XX待办已延期」。
23. 5 月 21 日，下次综合管理会自动创建 → 邀约中自动附带上次纪要 + 待办统计。

### 下次会议开场——闭环合上

24. AI 主持人开场：「上次会议 3 项待办：2 项已完成，1 项延期——张三的 Q2 前端重构，请说明。」
25. 整个循环再次启动。没有待办被遗忘，没有决议被搁置。

## 三、数据视角：永不停歇的闭环

```
会议 A ──→ 待办 1,2,3 ──→ 提醒/跟踪 ──→ 完成/延期
   │                                      │
   │          previousMeetingId            │
   └───────────── 自动关联 ───────────────┘
                 │
                 ▼
会议 B 开场 ──→ 通报 A 的待办 ──→ 新待办 4,5,6 ──→ 提醒/跟踪 ──→ ...
     │                                                              │
     └────────────── 每次会议都对上次有交代 ───────────────────────────┘
```

没有待办会被遗忘——延期的一直跟，直到完成或取消；完成情况在下次会议自动通报。闭环不是一次性的，而是永续循环。

## 四、最终形态的本质

| 维度 | 描述 |
|------|------|
| **用户体感** | 开会前不用准备，开会时只管说话，开完会不用整理，待办自动找人、自动催、自动跟 |
| **系统能力** | 从定时触发→邀约→主持→转写→纪要→待办→提醒→下次通报，全链路无人值守 |
| **人的角色** | 发言者 + 决策者。唯一需要人做的：在会上说话、在飞书卡片上点「完成/延期」 |
| **AI 的角色** | 主持人 + 记录员 + 秘书 + 催办员。AI 做掉了 80% 的会议运营工作 |
| **闭环价值** | 每次会议都对上次有交代，每次决议都有人跟到底，不再有「开会归开会、做归做」的断层 |
