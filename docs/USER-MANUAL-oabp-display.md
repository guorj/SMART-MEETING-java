# 会序 oabp 展示模板 — 运营配置手册

面向**非技术人员**：在会务预设后台为会序项配置 oabp 项目任务表格，**无需编辑 JSON**。
只需粘贴一段只读 SELECT SQL，后续列配置、筛选、排序均在向导中完成。

## 入口

1. 打开 **meeting-admin-server** 后台 → **会务预设**
2. 选择会务类型 → **会序与资料** 标签
3. 展开目标会序项 → **oabp 项目任务资料** 区域

默认进入 **简洁模式**。需要直接编辑模板 JSON 时可切 **专家模式**。

## Phase 3 重构（本次）

- **数据源仅保留自定义 SQL**：去掉 SQL 预设下拉，直接在 ① 粘贴/编辑 SELECT
- **列与 SQL 自动对齐**：探测字段后，列清单以 SQL 实际列为准；旧英文列名按中文标签自动迁移，非法 source 自动清除（消除「columns source 不在 SQL 结果列中」校验错误）
- **筛选与排序整合进每一列**：移除独立 ④ 区块；每列行内可设筛选条件与排序优先级
- **多列排序**：每列可选优先级 1、2、3…，按优先级生成 `sort` 数组
- **合计行** 配置移至 ② 展示方式

## 3 分钟配置（简洁模式）

### ① 数据源（自定义 SQL）

在文本框中粘贴只读 SELECT 语句，例如：

```sql
SELECT task_name AS 待办事项, status_code AS 状态, progress AS 进度,
       plan_date AS 截止日期, start_date AS 开始日期
FROM jq_project_task_tracking WHERE deleted = 0
```

修改后约 **1 秒**自动探测字段并更新下方列配置。探测状态显示在文本框下方（如「已探测字段：待办事项、状态、进度…」）。

仅支持只读 SELECT；写入语句会被后端校验拒绝。

### ② 展示方式

1. 可选 **展示模板预设**（如「项目任务（按状态分组）」）→ 点 **应用**
2. 或手动选 **平铺表格** / **按状态分组展示**
3. 填写 **表格标题**（主持页显示）
4. 勾选 **显示合计行** → 填合计标签 + 勾选需要求和的数值列（如进度）

### ③ 显示列（含筛选与排序）

每列一行，从左到右：

```
≡  ☑  [列标题]  [宽px]  [筛选 op ▼] [筛选值]  [排序序 无|1|2|3 ▼] [升序/降序 ▼]
```

- **≡** 拖动调整列顺序
- **☑** 勾选是否显示该列
- **列标题** 可改中文显示名
- **宽** 列宽（px）
- **筛选 op**：选「无筛选」或比较运算（等于 / 不等于 / 包含 / 为空 等）；选非空运算后出现值输入框，枚举字段以下拉选择数据采样值
- **排序序**：选「不排序」或优先级 1、2、3…（1 = 首要排序键）；支持多列排序，优先级不可重复（重复时预览会提示）
- **升序/降序**：仅当设了排序序后生效

列清单始终与 SQL 实际列对齐：修改 SQL 列名或增删列后，列配置自动 reconcile，非法列消失、新列补全。

### 预览与保存

- 修改任意项后约 **1 秒**自动刷新 **实时预览**
- 预览显示「共 N 条（筛选后）」；有校验问题时显示橙色提示
- 配置 **自动保存** 到会务预设（与现有会序 autoSave 一致）

### 主持页展示

勾选 **主持页展示**；取消勾选则 SQL 仍可用于后台任务，主持页不显示表格。

**主持页展示不依赖「资料绑定」**：即使该会序项未绑定任何飞书/本地资料（资料绑定数为 0），只要配置了 SQL + 展示模板并勾选「主持页展示」，主持页会序资料面板即会渲染项目任务表格。OABP 配置与资料绑定是两条独立链路，可单独使用，也可组合使用。

## 清除模板（恢复现网行为）

点 **清除展示模板** → 删除 `oabpDisplayTemplate`，主持页回退到原始 SQL 直出 + 旧 JS 渲染逻辑。

## 改模板后已有会议何时生效？

- **未开始的会议**：改 preset 后需点 **执行刷新未开会**，将新 `host_agenda` 写入会议快照
- **进行中/已结束会议**：使用创建时快照，不自动变更
- **刷新不丢 OABP 配置**：刷新未开会时，会序项的 `oabpTaskSql` / `oabpTaskShow` / `oabpDisplayTemplate` 会一并写入会议快照；无资料绑定的会序项也完整保留 OABP 配置

## 专家模式（技术人员）

切换 **专家** 后可：

- 手写/修改 SQL textarea
- 编辑展示模板 JSON
- 探测字段 / 预览效果
- 编辑枚举列的 map 键值对

JSON 高级 tab 仍可编辑完整 `host_agenda`；改 JSON 后需重新 **加载** preset 刷新表单。

## 常见问题

| 现象 | 处理 |
|------|------|
| 列配置显示英文 source 且校验报错 | 已由 Phase 3 自动对齐修复；如仍出现，修改 SQL 触发重新探测或点「清除展示模板」重建 |
| 预览「无法连接数据源」 | 检查 meeting-server `MEETING_DB_OABP_ENABLED` 与 oabp 库连通 |
| 筛选后 0 条 | 放宽筛选条件 |
| 排序优先级重复 | 每列优先级唯一，调整后预览自动校验 |
| 主持页仍是旧样式 | 确认已配展示模板且 part 含 `displayMeta`；无模板时走旧逻辑 |
| 改了 preset 主持页没变 | 对未开会执行 **刷新未开会** |
| 只有 SQL 无资料绑定时主持页不显示 | 已修复：OABP 与资料绑定解耦；确认已勾选「主持页展示」并执行 **刷新未开会** |

## 相关 API（开发参考）

| 方法 | 路径 |
|------|------|
| GET | `/api/v1/admin/agenda-config/oabp-display/presets` |
| GET | `/api/v1/admin/agenda-config/oabp-display/options` |
| POST | `/api/v1/admin/agenda-config/presets/{code}/agenda/{index}/oabp-columns` |
| POST | `/api/v1/admin/agenda-config/presets/{code}/agenda/{index}/oabp-preview` |

存储位置：`host_agenda.items[i].oabpTaskSql` + `oabpDisplayTemplate`（`oabpSqlPresetId` 固定为 `custom`）。
