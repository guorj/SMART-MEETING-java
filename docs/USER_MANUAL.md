# 智能会议纪要系统 — 用户操作手册

> 版本：v3.1 | 日期：2026-05-09 | 系统：smart-meeting-java
> 交互方式：**飞书对话**，群聊或单聊均可，全程无需离开飞书

---

## 1. 快速开始

### 使用方式

机器人支持两种使用方式，指令完全相同：

| | 🏢 群聊 | 👤 单聊 |
|------|:---:|:---:|
| 怎么用 | 把机器人拉到项目群 | 直接打开机器人对话窗口 |
| 谁能看到 | 群成员都可见 | 仅自己可见 |
| 参会人 | 群成员自然参与 | 在指令中指定姓名即可 |
| 卡片推送 | 推送到群里 | 推送到对话 |
| 适合场景 | 团队例会、项目评审 | 个人速记、1v1 访谈 |

> 💡 两种方式下所有指令都一样，系统会根据上下文自动适配。
>
> **最快体验**：飞书搜索「智能会议纪要」→ 打开对话 → 直接发指令。

### 第一步：发送指令

在飞书对话中（群聊或单聊均可）发送：

> 开始会议 主题:Q2产品评审 参会人:张三,李四,王五

机器人立刻回复一张蓝色卡片：

```
┌──────────────────────────────────────┐
│ 🎙️ 智能会议已启动                     │
│                                      │
│ 📋 主题：Q2产品评审                    │
│ 🕐 开始时间：2026-05-09 16:00          │
│ 🆔 会议ID：61ce166d-2223-41b4         │
│ ──────────────────────────────────── │
│ [ 🎤 点击开始录音 ]                    │
│ ──────────────────────────────────── │
│ 💡 点击按钮直接打开录音页面             │
│ 📌 结束时发送"结束会议"自动生成纪要      │
│ ⏱️ 最大录音时长4小时                   │
└──────────────────────────────────────┘
```

### 第二步：点击卡片 → 打开录音页面 → 授予麦克风权限 → 开始实时转写

录音页面上实时显示：

```
🔴 录音中  00:15:23

👤 张三：今天我们讨论Q2的产品方向...
👤 李四：前端团队已经完成了组件重构...
👤 王五：后端接口预计下周上线...
```

### 第三步：结束会议

主持人（会议创建者）发送：

> 结束会议

机器人回复：

```
⏳ 会议录音已结束，正在生成纪要...
```

约 20-30 秒后，推送绿色卡片：

```
┌──────────────────────────────────────┐
│ ✅ 会议纪要已生成                      │
│                                      │
│ 📋 主题：Q2产品评审                    │
│ ⏱️ 会议时长：45分钟                    │
│ 👥 识别到 3 位发言人                   │
│ ──────────────────────────────────── │
│ [ 📄 打开飞书文档 ]                    │
│ ──────────────────────────────────── │
│ 📌 待办事项：4项（详见文档）            │
│ 👤 责任人：张三(1项), 李四(2项), 王五(1项)│
└──────────────────────────────────────┘
```

### 第四步：点击「打开飞书文档」

飞书自动打开结构化会议纪要，包含：
- 📋 会议概览（时间、参与人、时长）
- 📝 议题与讨论（按发言人标注）
- ✅ 决议与决策
- 📌 待办事项（含责任人和优先级）

## 2. 完整指令参考

| 指令 | 说明 | 示例 |
|------|------|------|
| `开始会议` | 创建并开始会议 | `开始会议 主题:周例会 参会人:张三,李四` |

## 3. 场景操作详解

### 场景一：声纹注册（让系统知道"谁在说话"）

> **群聊和单聊都能用**。在单聊中注册后，群聊会议也能自动识别。

1. 发送指令：

   > 注册声纹 姓名:张三

2. 点击机器人回复卡片中的「点击开始注册」

3. 按提示朗读 3 句话 → 完成注册

4. 声纹有效期 10 年，后续所有会议自动匹配

---

### 场景二：跨设备加入会议

> 常用于多人会议场景（群聊中每个参会人单独加入以加载自己的声纹）

> 加入会议 会议ID:61ce166d-2223-41b4

---

### 场景三：下次会议自动通报进度

> 每次开会前自动汇报上次待办完成情况，形成闭环

下次会议正常发送「开始会议」，机器人会先推送：

```

│ Q2产品评审                             │
│                                      │

```

```
        ▼
   ISSUE_COLLECTING ──→ 自动 STARTED
        │
        ▼
   点击卡片 → RECORDING
        │
        ▼

        │
        ▼
   PROCESSING（约20-30秒）
        │
        ▼
   COMPLETED ──→ 飞书文档生成
        │
        ▼
   TODO_TRACKING（待办跟踪）
        │
        ▼

```

## 6. 常见问题

**Q：群聊和单聊有什么区别？**

A：指令完全一样。区别在于消息可见范围：群聊全群可见，单聊仅自己可见。单聊适合个人速记，群聊适合团队会议。

**Q：录音时网络断了怎么办？**

A：重新打开录音页面链接，30 秒内可无缝续传。

**Q：声纹识别不准怎么办？**

A：重新发送「注册声纹」即可覆盖。

**Q：会议最长多久？**

A：最长 4 小时，超时自动停止并提醒。

**Q：谁可以结束会议？**

A：只有创建者可以结束。
